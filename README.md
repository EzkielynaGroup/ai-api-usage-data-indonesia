# AI API usage data, Indonesia (Ezkielyna)

Daily open dataset of **which AI models developers call through Ezkielyna**, an independent AI API gateway used mostly by Indonesian developers: weekly usage ranking, per-model reliability and latency, and list prices. Updated every day by GitHub Actions from public JSON files. License **CC BY 4.0**.

> **Read this first:** the numbers come from **one gateway**, not the whole Indonesian market. Most users are developers running coding agents (OpenCode, Claude Code and similar), and the ranking usually has **tens of users per model**. Treat it as an honest sample, not national market share.

## What is in this repo

| Path | What |
|---|---|
| `latest/leaderboard.json` | 7-day usage ranking vs the 7 days before (newest run) |
| `latest/models.json` | per-model success rate, uptime, time to first token, output speed, request counts (newest run) |
| `latest/pricing.json` | list price per model in USD, public key groups only (newest run) |
| `data/YYYY/MM/DD/*.json` | the same three files for every day since 11 Nov 2026 (date = run date in WIB, UTC+7) |
| `reports/` | monthly recaps written from the snapshots ([November 2026, weeks 1-2](reports/2026-11-minggu-1-2.md), in Indonesian) and the exact data they used (`reports/data/2026-11-11/`) |
| `scripts/update.py` | the updater (Python standard library only) |
| `tests/` | unit tests for the updater with recorded fixtures |

Sources, fetched once a day at 01:15 UTC (08:15 WIB) without any key:

- https://api.ezkielyna.store/status/leaderboard.json
- https://api.ezkielyna.store/status/models.json
- https://api.ezkielyna.store/api/pricing

What the updater changes: it removes model ids containing `uncensored`, `abliterated` or `nsfw` (content policy of this dataset), drops cosmetic icon names, keeps only public key groups in the price file and converts raw ratios to USD prices. Everything else is copied as published. A commit is made only when a file actually changed.

## Schema

### `leaderboard.json`

| Field | Meaning |
|---|---|
| `generated_at` | when the gateway built the ranking (ISO 8601, +07:00) |
| `window.start` / `window.end` | the 7-day window; `prev_start` / `prev_end` = the week before |
| `models.min_users` | a model is ranked only if at least this many distinct users called it (3) |
| `models.items[].rank`, `model`, `vendor` | rank by requests, model id as served, model maker |
| `requests`, `prompt_tokens`, `completion_tokens`, `tokens` | answers and tokens in the window |
| `users` | distinct users who called the model |
| `share_pct` | share of the window's requests as published by the gateway (the listed models add up to a little under 100%) |
| `rank_prev`, `requests_prev`, `change_pct`, `is_new` | the previous week, for week-over-week change |
| `apps` | top client apps from user agents (partial data since 10 Nov 2026; only apps with at least 3 clients and 50 requests) |

### `models.json`

`models.<id>` per model id:

| Field | Meaning |
|---|---|
| `kind`, `vendor` | family (deepseek, gpt, claude, image, video, audio, other, ...) and maker; vendor `Ezkielyna` marks a routing alias such as `auto` |
| `requests_24h`, `requests_7d`, `requests_30d` | answers counted per window |
| `success_24h`, `uptime_7d`, `uptime_30d` | % of requests without a gateway or upstream 5xx error; `null` when the window has too few requests |
| `ttft_ms_p50`, `ttft_ms_p90` | time to first token of streamed answers, last 24 h (ms) |
| `latency_s_p50` | median total answer time, last 24 h, in whole seconds (not described in the source notes; read with care) |
| `tps_p50` | median output tokens/s of streamed answers with at least 50 output tokens and 2 s of generation (estimate) |
| `low_data` | fewer than 20 answers in 24 h: latency and speed are `null` |

The file's own `notes` object repeats these definitions.

### `pricing.json`

| Field | Meaning |
|---|---|
| `groups.<name>` | public key groups with their label and price multiplier (Standard/`default` 1x, Media 1x, Hemat/`free` 1x, Premium 1.5x, Pro 3x) |
| `models[].id`, `vendor`, `tags`, `endpoints` | model id, maker, type tags (Vision, Image, TTS, ...) and API formats (`openai`, `anthropic`, `openai-response`, `image-generation`, ...) |
| `models[].key_groups`, `multiplier` | groups that can call it, and the lowest multiplier among them (already applied to the prices) |
| `billing` | `tokens`, `per_call`, `characters` (speech) or `audio_minutes` (transcription) |
| `input_usd_per_1m`, `output_usd_per_1m`, `cached_input_usd_per_1m` | for `tokens` and `characters`: USD per 1M tokens (or characters); cached input only where it is cheaper |
| `price_usd`, `unit` | for `per_call`: USD per `image`, `second`, `request` or `call` |

Price rule (the same one the gateway uses in its public [llms-full.txt](https://api.ezkielyna.store/llms-full.txt)): input = `model_ratio` × $2 per 1M, output = input × `completion_ratio`, per-call = `model_price`, all × the lowest public group multiplier. For `audio_minutes` the per-1M figure is the raw rate; the real charge depends on audio length. To convert to rupiah, the gateway's public price list uses Rp15.000 per USD (the $1 API Credit pack; larger packs cost less per dollar).

## Limits

- **One gateway.** Popularity here reflects who uses Ezkielyna (many coding-agent users), its prices and its routing, not the Indonesian or global market.
- **Small numbers.** A ranked model may have only 3 users; big percentage swings on small bases mean little.
- **Reliability is the gateway's view.** Uptime counts gateway and upstream 5xx errors for this gateway's traffic only; it is not the model vendor's own status.
- **Latency depends on prompt size.** Coding agents send prompts above 100k tokens, so time to first token is higher than in a chat app.
- **Prices change.** Each snapshot shows the list price on that day only.
- Ids are written exactly as the gateway serves them, so `deepseek-v4.1-flash` and `deepseek-v4.1-flash-1017` are counted separately.

## FAQ

**Which AI models do Indonesian developers use most?**
On Ezkielyna, in the week 4-11 November 2026, the two DeepSeek V4.1 Flash ids took 85.8% of requests (published `share_pct`), and DeepSeek models had 90.98% of the requests of the 20 listed models; OpenAI 6.24% and Anthropic 1.34% ([recap](reports/2026-11-minggu-1-2.md)). That is one gateway's sample, not national market share. The table above has the current week.

**Why are almost all tokens input tokens?**
99.35% of tokens in that week were prompt tokens. Coding agents resend files and conversation history at every step (an average deepseek-v4.1-flash-1017 request carried about 124k tokens), so input and cache prices matter more than output prices for these users.

**Which model answers fastest?**
In the 11 Nov 2026 snapshot, GPT models started answering sooner (median time to first token 2.5-3.1 s) while DeepSeek V4.1 Flash started later (4.5-5.4 s, with prompts above 100k tokens) but generated output about three times faster (133-143 vs about 45 tokens/s). See `latest/models.json` for today.

**How much does DeepSeek V4.1 Flash cost through this gateway?**
On 11 Nov 2026 the list price was $0.04 per 1M input tokens, $0.16 per 1M output tokens and $0.0054 per 1M cached input tokens (about Rp600 / Rp2.400 per 1M at Rp15.000/USD). Other providers price differently; check `latest/pricing.json` for the current figure.

**How often is this updated?**
Daily at 01:15 UTC (08:15 WIB) by the workflow in `.github/workflows/update.yml`. The ranking itself covers a rolling 7-day window.

**Can I use this data commercially?**
Yes, under CC BY 4.0: credit "Data: Ezkielyna, CC BY 4.0 — https://ezkielyna.store/peringkat".

**Tanya jawab**
